# Politique de securite

## Versions prises en charge

La branche `main` et les deploiements issus de cette branche recoivent les correctifs de securite.

## Signaler une vulnerabilite

Ne publiez pas de details exploitables dans une issue publique. Envoyez plutot un rapport a [pulsateach@gmail.com](mailto:pulsateach@gmail.com) avec :

1. une description claire du probleme ;
2. les etapes de reproduction ;
3. l'impact potentiel ;
4. une recommandation de correction, si vous en avez une.

Nous accuserons reception, evaluerons le rapport et coordonnerons une correction avant toute divulgation publique. Ne joignez jamais de cles, jetons, cookies ou donnees utilisateur au rapport.

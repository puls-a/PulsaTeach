# Prompt de génération du logo PulsaTeach

Crée un logo vectoriel premium, simple et mémorable pour **PulsaTeach**, une
plateforme moderne et gratuite d’apprentissage du développement web.

Direction créative :

- symbole principal : une paire d’accolades `{ }` qui forme subtilement une
  impulsion, une étincelle ou un chemin de progression ;
- idée à transmettre : code, apprentissage, énergie, progression et confiance ;
- style : géométrique, minimal, chaleureux, précis, légèrement ludique mais
  jamais enfantin ;
- identité originale, sans ressembler aux logos de Codecademy, freeCodeCamp,
  OpenClassrooms, Udemy, GitHub ou Visual Studio Code ;
- formes lisibles à 16 px, silhouette forte et espaces négatifs propres ;
- palette principale : violet électrique `#5546F6`, bleu nuit `#10172A`, blanc ;
- accent facultatif très discret : menthe `#39D6A3` ;
- typographie du mot-symbole : sans-serif moderne, ronde mais professionnelle,
  excellente lisibilité ; mettre visuellement l’accent sur “Teach” sans casser
  l’unité du nom ;
- produire une version horizontale avec symbole + “PulsaTeach”, une version
  icône seule, une version monochrome noire et une version blanche ;
- fond transparent, aucun mockup, aucune ombre 3D, aucun dégradé complexe,
  aucun ordinateur, livre, ampoule, chapeau universitaire ou mascotte ;
- rendu parfaitement plat, vectoriel, équilibré et exploitable comme favicon,
  icône d’application, en-tête web et avatar social.

Livrable visuel demandé : planche propre sur fond neutre présentant les quatre
variantes, avec marges de sécurité cohérentes. Le symbole doit rester
reconnaissable seul et ne contenir aucun petit détail fragile.

Texte exact à afficher : **PulsaTeach**.

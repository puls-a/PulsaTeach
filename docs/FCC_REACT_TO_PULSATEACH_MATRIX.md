# Matrice d'inspiration React / Front End Libraries v9

Source consultée localement : `.external/freeCodeCamp/curriculum/structure/superblocks/front-end-development-libraries-v9.json`.

Objectif : reprendre la granularité pédagogique et la progression type freeCodeCamp
sans copier les textes, exercices ou solutions. Le contenu PulsaTeach reste original,
bilingue, orienté revue de code, accessibilité, preuves et production.

## Correspondance

| Repère freeCodeCamp | Bloc PulsaTeach ajouté | Intention PulsaTeach |
| --- | --- | --- |
| React fundamentals, JSX, composants réutilisables | `react-v9-jsx-components` | JSX lisible, composants sémantiques, contrats vérifiables |
| Reusable navbar/footer/profile card, mood board | `react-v9-props-composition` | Props minimales, children, callbacks, cartes composées |
| State and responding to events | `react-v9-state-events` | État minimal, updates fonctionnelles, rendu conditionnel, listes stables |
| Forms in React | `react-v9-forms-a11y` | Labels, erreurs reliées, focus, statuts et validation accessible |
| Effects and referencing values | `react-v9-effects-hooks` | Effets limités à la synchronisation, cleanup, refs et hooks personnalisés |
| Data fetching, memoization, routing | `react-v9-async-routing` | États réseau, annulation, retry, URL, focus de navigation |
| Redux / shared state progression | `react-v9-state-management` | Décision local/reducer/context/store, sélecteurs, non-mutation |
| Testing, performance, cert projects | `react-v9-quality-performance` | Tests utilisateur, API mockée, lazy routes, budget de rendu, capstone |

## Résultat attendu

- 8 nouveaux modules React progressifs.
- 48 micro-leçons pratiques.
- 8 mini-projets ou projets, dont un capstone React.
- 8 quiz de 5 questions chacun avec scoring renforcé.
- Cours enrichis automatiquement par `createProfessionalTrack` : objectifs,
  sections, vocabulaire, erreurs fréquentes, guide, rubriques et preuves.

## Garde-fous éditoriaux

- Aucun texte freeCodeCamp n'est repris tel quel.
- Les exemples utilisent des scénarios PulsaTeach : formations, progression,
  préférences, dashboard, suivi d'apprentissage.
- Chaque activité demande une preuve observable : rôle accessible, état,
  test, cleanup, focus, URL ou budget.
- Les projets gardent une durée suffisante pour éviter les exercices creux.

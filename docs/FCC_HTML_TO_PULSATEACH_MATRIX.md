# Matrice benchmark freeCodeCamp → PulsaTeach — HTML

Date de mise à jour : 2026-06-30

Objectif : renforcer HTML avec la granularité atelier de freeCodeCamp, sans
copier ses textes. PulsaTeach adapte les exercices à PulsaConf, aux pages de
cours publiques, au SEO, aux mentions légales, aux formulaires et à
l’accessibilité.

## Adaptation PulsaTeach

| Compétence benchmark | Adaptation PulsaTeach | Preuves |
| --- | --- | --- |
| Squelette HTML | Doctype, `lang`, `charset`, `title`, structure head/body | `legacyHtmlModulesFoundation.js` |
| Contenu sémantique | Titres, sections, articles, listes, images, navigation | `legacyHtmlModulesFoundation.js`, `legacyHtmlModulesWorkshop.js` |
| Formulaires | Labels, contraintes natives, fieldset, aides, autocomplete, statut | `legacyHtmlModulesAdvanced.js`, `legacyHtmlModulesHardening.js` |

| SEO/publication | Canonical, meta description, viewport, favicon, Open Graph | `legacyHtmlModulesHardening.js` |
| Données riches | Tableaux avec caption/scope, `time`, `data` | `legacyHtmlModulesHardening.js` |
| Projet final | Page publiable auditable, sans lien vague, avec formulaire/tableau/média | `html-14-production-audit-project` |

## Résultat du lot

- HTML passe à 44 leçons, 6 modules, 5 projets/labs.
- 248 critères de validation.
- Ratio `5.6 tests/leçon`.
- Audit pédagogique et audit profondeur verts.
- Contenu original PulsaTeach, aucun texte freeCodeCamp copié.

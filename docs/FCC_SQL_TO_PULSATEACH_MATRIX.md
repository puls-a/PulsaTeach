# Matrice d'inspiration SQL / PostgreSQL

Sources benchmark consultées localement dans `.external/freeCodeCamp` :

- `relational-databases-v9.json` (superblock)
- `lecture-working-with-relational-databases.json`
- `lecture-working-with-sql.json`
- `lecture-understanding-the-command-line-and-working-with-bash.json`
- `lecture-understanding-bash-scripting.json`

Le contenu PulsaTeach ne copie pas freeCodeCamp. Il reprend la granularité :
micro-leçons, workshops, labs, quiz fréquents et projets vérifiables.

| Repère benchmark | Bloc PulsaTeach ajouté | Angle original PulsaTeach |
| --- | --- | --- |
| Bash fundamentals & psql basics | `sql-v9-cli-psql` | Maîtrise de l'outil `psql`, variables, flags, imports CSV, et scripts shell basiques pour automatisation. |
| Basic SQL (CRUD) | `sql-v9-crud-fundamentals` | Syntaxe SQL moderne, types avancés PostgreSQL, et bonnes pratiques de nommage. |
| Advanced queries & joins | `sql-v9-advanced-queries` | Jointures complexes, Window functions, requêtes imbriquées et CTE (Common Table Expressions). |
| Database design & normalization (Projects) | `sql-v9-modeling-normalization` | Normalisation 1NF-3NF, conception de schémas scalables, contraintes complexes. |
| Security & Roles | `sql-v9-roles-security` | Gestion fine des Rôles, GRANT/REVOKE, isolation inter-tenant avancée, et audit. |

## Résultat

- 5 nouveaux modules SQL/PostgreSQL.
- 30 micro-leçons.
- 5 projets.
- 5 quiz de 5 questions.
- Parcours orienté modélisation propre, requêtes analytiques, et sécurité robuste.

## Garde-fous

- Pas de texte freeCodeCamp copié.
- Les exemples utilisent des scénarios PulsaTeach : projets, e-commerce, multi-tenant.
- Chaque activité demande une preuve de concept (requête valide, plan d'exécution, etc.).

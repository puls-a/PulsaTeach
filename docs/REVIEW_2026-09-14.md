## Portée des preuves

Vérification finale : `npm run validate` réussi (226 tests unitaires et tous les
audits), `npm run test:api` réussi (27 tests), `npm run test:e2e` réussi
(140 tests, 44 exclusions conditionnelles). Aucun avertissement éditorial.

Les transitions de couleur des onglets ont été retirées : leur interpolation
pouvait produire temporairement un contraste inférieur à 4,5:1.

Les tests navigateur vérifient le lien d'évitement, les disclosures natives,
les formulaires et un audit axe dans les quatre aperçus HTML sur desktop/mobile.
Ils complètent les tests unitaires des solutions et des régressions volontaires.

Le sandbox conserve `allow-scripts` seul et `form-action 'none'` : le retour de
formulaire est une simulation, pas une preuve d'envoi HTTP ou de stockage serveur.
Les noms des champs sont affichés, pas les valeurs saisies. Pour vérifier le trajet
HTTP, servir le document avec l'API locale et inspecter sa réponse séparément.

Une alternative descriptive reste une heuristique : la pertinence par rapport à
l'image nécessite une revue humaine. L'audit JSON-LD n'est pas un validateur complet
de Schema.org. Axe ne prouve pas à lui seul la conformité accessibilité.

Le reset des migrations Supabase et les E2E Supabase distants ne font pas partie de
cette validation locale. Le budget CSS passe encore avec une marge d'environ 4 Ko.

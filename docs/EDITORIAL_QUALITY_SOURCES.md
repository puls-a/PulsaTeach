# Référentiel éditorial PulsaTeach

PulsaTeach peut s’inspirer de la structure pédagogique publique du web, mais ne
doit pas copier les cours, exemples ou formulations de plateformes tierces.
Chaque leçon doit produire une compétence vérifiable, contextualisée et
réutilisable dans un vrai projet.

## Sources de référence autorisées

- MDN Learn Web Development : progression HTML, CSS, JavaScript, accessibilité
  et pratiques de développeur front-end.
- MDN Curriculum : compétences essentielles attendues d’un nouveau développeur
  front-end.
- web.dev Learn : performance, responsive design, HTML, CSS, formulaires,
  images, Core Web Vitals et accessibilité.
- W3C WAI Tutorials : alternatives textuelles, formulaires, titres, structure
  de page et vérifications d’accessibilité.
- Google Search Central : SEO technique, sitemap, exploration, données
  structurées et qualité des contenus indexables.

## Règles de rédaction

Chaque leçon doit contenir :

- un problème réel à résoudre ;
- un vocabulaire relié au glossaire ;
- un exemple minimal utile ;
- un contre-piège ou une erreur fréquente ;
- une preuve de validation manuelle ou automatisée ;
- une mini-revue expliquant utilisateur, risque, décision et limite ;
- une phrase de transfert vers un contexte de production.

Chaque quiz doit contenir :

- au moins six questions pour un bilan de module ;
- au moins dix questions pour un examen ;
- plusieurs types de questions ;
- du feedback bilingue ;
- au moins une question de diagnostic ou de justification ;
- des distracteurs plausibles qui testent la compréhension, pas la mémoire.

## Anti-patterns refusés

- copier ou paraphraser fortement un cours externe ;
- multiplier des leçons creuses pour gonfler le catalogue ;
- proposer un quiz de définitions seulement ;
- valider une compétence sans preuve reproductible ;
- confondre score Lighthouse, axe ou build vert avec qualité réelle.

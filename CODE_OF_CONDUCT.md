# Code de conduite

PulsaTeach souhaite offrir un espace ouvert, respectueux et utile a toutes les personnes qui apprennent ou contribuent.

Nous attendons des echanges constructifs, inclusifs et centres sur le produit. Le harcelement, les attaques personnelles, les propos discriminatoires, la divulgation de donnees personnelles ou les comportements intimidants ne sont pas acceptes.

Signalez un comportement problematique a [pulsateach@gmail.com](mailto:pulsateach@gmail.com). Les signalements sont traites de maniere privee et peuvent mener a un avertissement, une moderation ou une exclusion selon leur gravite.

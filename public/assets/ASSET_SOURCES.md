# PulsaTeach Assets

The assets currently committed in this folder are original lightweight SVGs made for PulsaTeach. They are safe to use and can be replaced later by stronger art packs.

## Folders

- `ui`: interface frames, panels, HUD pieces.
- `icons`: gameplay icons such as targets, arrows, badges.
- `characters`: PulsaTeach characters and avatars.
- `backgrounds`: academy maps and world scenes.
- `effects`: sparks, particles, success markers.
- `audio`: reserved for future feedback sounds.

## Reviewed External Sources

- Kenney assets are the preferred future source because many packs are released as CC0/public domain.
- OpenGameArt can be useful, but every item must be checked individually because licenses vary.
- itch.io free UI/pixel packs can be good, but each pack has its own license and commercial terms.
- CraftPix freebies should also be reviewed per asset before use.

Do not add third-party assets here unless the license file or source URL is stored next to the asset.
